# Website lessons
- A full square logo cannot be treated as a raven-only icon. Display the supplied lockup legibly without reconstructing the wordmark.
- Lifecycle and ordering availability are separate. A working build does not establish stock or sale terms.
- Every file under public is published, including unused screenshots. Review the directory as well as rendered pages.
- A static contact form cannot receive inquiries. Show truthful unavailable/draft behavior until a real route is configured; never claim delivery from a click.
- Build-time draft filtering must apply to pages, catalog, contact choices and client bundles.
- Local source evidence referencing private repositories belongs in an ignored authoring register, even though docs is outside the browser build: the site Git repository itself is public.
